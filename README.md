# Python Billing System

A simple Python command-line billing system that calculates subtotal, discount, tax, and final amount for a shopping cart.

## Files
- `bill.py`: Contains the logic to calculate totals, discounts, taxes, and to display the final bill.
- `index.py`: The main menu program where users can add items to a cart and view the bill.

## How to Run
1. Make sure Python is installed.
2. Open your terminal in this folder.
3. Run: `python index.py`
